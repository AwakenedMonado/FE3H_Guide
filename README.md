# FE3H Guide Revamped

This project was originally developed by  xianacarrera as a FE3H companion app several years ago. I happened to stumble upon it and enjoyed what it offered, while simultaneously wishing it had several other features to check about the game. 

I am now in the process of continuing development. I don't really have a desire to create drastically different UI changes or anything, just build upon what already exists while focusing on adding relevant content about the game (and hopefully avoid the need to have 20 tabs open every session ^-^).

The project remains open-source, and contributions, feedback, and collaboration are welcome. Please note that portions of the code may be reworked significantly over time as the app evolves.
